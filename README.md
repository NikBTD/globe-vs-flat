# Globe vs Flat Earth

Live site: https://nikbtd.github.io/globe-vs-flat/

Two models of the Earth, side by side: the globe and the flat Earth (Gleason map). Pick any place and time and compare the sky each model predicts with the real sky.

- Real Sun and Moon positions: [Astronomy Engine](https://github.com/cosinekitty/astronomy) (MIT)
- Stars: Hipparcos catalogue via [d3-celestial](https://github.com/ofrohn/d3-celestial) (BSD)
- Earth images: NASA Blue Marble and Black Marble (public domain); coastlines: Natural Earth (public domain)
- 3D rendering: three.js (MIT); fonts: Archivo and IBM Plex Mono (SIL Open Font License)

The site is one self-contained page (`index.html`). It collects no data: no analytics, no cookies, no sign-in, no outside requests. Preferences (language, units, time zone, saved places) stay in the visitor's own browser.
